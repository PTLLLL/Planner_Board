# Planner Agent 前端视觉重构说明

## 设计方向

根据项目文档，Planner Agent 是目标驱动的可控 AI 日程规划工具。前端视觉采用「浅蓝白底 + 蓝色主操作 + 青色进度 + 琥珀/玫红状态」的轻量 SaaS 风格，强调信息密度、可扫描性和可控感。

## 设计令牌

- 背景：浅蓝灰 `215 33% 97%`
- 主色：蓝 `220 91% 54%`
- 辅助色：青 `199 89% 48%`
- 强调色：青绿 `172 78% 38%`
- 警示：琥珀 `38 92% 50%`，错误：玫红 `350 89% 60%`
- 卡片圆角：`0.5rem`，阴影使用柔和层级
- 图标：lucide-react

## 组件与页面

- `AppShell`：桌面侧栏、品牌区、导航分组、待确认/目标数量徽标、移动端底部横向导航
- 共享 UI：Button、Card、Input、Textarea、Select、Badge、Dialog、Tabs、Table、Skeleton
- 落地页：产品预览月历 + Agent 建议卡
- 登录/注册：品牌侧栏 + 表单
- 仪表盘：Agent 请求横幅、指标卡、周负载图、目标进度、最近动作
- 日历：月历网格、今日/选中态、任务芯片
- 每日任务：表单与列表双栏、优先级色轨、完成率
- 目标：卡片网格、状态页签、拆解/完成/归档操作
- Agent 收件箱：运行分组、风险/置信度徽标、子任务选择、编辑并接受
- Agent 控制台：运行表 + 详情、指标卡、健康度
- 评估：指标卡、用例/结果表、Bad Case 汇总
- 设置：账户、偏好、旧数据导入
